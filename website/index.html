🔥 Our Signature Innovation

20-Second Sequential Cascade Burner Chats.

Other apps start deleting messages before you even finish reading the first one—or worse, start the timer when the sender hits send! We fixed disappearing messages for good.

1

Activates ONLY when the recipient views it

When you send 3 messages to Elena, nothing burns while she’s offline. Your screen shows ⏳ Unread by Elena (burns 20s once viewed). The first 20-second clock only starts the exact millisecond Elena opens the chat in @me.

2

One-after-another sequential cascade (20s × N)

Have 3 messages waiting? Message #1 burns for 20s while Messages #2 and #3 sit safely in queue (⏳ queued (20s)). Only when Message #1 deletes does Message #2 start its 20s timer. 3 messages = 60 full seconds to read!

3

Independent read times in Group Chats

In group burner chats, every friend gets their own personal 20s cascade! If Elena opens the group at 4:00 PM, her copy burns in 60 seconds. If Sam opens the group at 4:30 PM, all 3 messages are still waiting for him and run his own 60-second cascade. And on the sender's screen, the message only vanishes once every group member has finished burning it!

FAQ

Everything you’re wondering, answered straight.

How does the 20-second sequential cascade work in Burner Chats?

When you send messages in a 🔥 Burner Chat, the timer does not start when you press send. It only activates when the receiving user actually opens and views the message in the app. Once viewed, Message #1 counts down for 20 seconds and deletes, which immediately triggers Message #2’s 20-second timer, and so on (3 messages = 60 seconds total). In group chats, every member has their own independent cascade based on when they personally view the chat!

Wait—if it uses email, will my normal inbox get spammed?

Zero clutter. @me uses a strict cryptographic packet gatekeeper that ignores 100% of regular emails (school updates, receipts, newsletters) and files encrypted DCP/1.0 packets out of sight. Inside @me, you only ever see your friends and group chats.

Can Google, Yahoo, my school, or @me read my messages?

No. Every message, poll, reaction, and attachment is encrypted on your device using OpenPGP (Curve25519) before it ever leaves your screen. Email providers only transport scrambled ciphertext they have no key to unlock, and @me runs zero servers of its own.

Why is “recycling old email technology” better than building a new server?

Every startup chat app eventually runs out of server money, starts showing ads, sells user data, or gets blocked on school/home Wi-Fi. Because email is a 50-year-old universal protocol already allowed on every device on Earth, recycling it gives us an indestructible global network for $0.

Can someone turn off the burner timer in a Burner Chat?

No. A Burner Chat must be created from the start as a Burner Chat (via the 🔥 icon in Friends, Groups, or the + menu) and is permanently locked to the 20-second sequential cascade for everyone in that chat.
