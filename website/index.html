2. Best Practices

The AI Coding + Git Version Control Loop

AI writes code fastest when you give it tight boundaries and Git safety nets. Follow this 4-step rhythm for every feature you add.

Stable Base: simple
init scaffold google oauth fix 10/10 vitest pass
↳ git checkout -b feat/in-chat-polls  (isolate each AI experiment!)
Feature Branch: feat/*
write type + parser add vitest check wire React UI git commit & merge
RULE 01

One Feature Per Branch

Never ask AI to overhaul 5 systems at once on simple. Run git checkout -b feat/my-feature first so you can revert with one command if an experiment goes sideways.

RULE 02

Point AI to Protocol Contracts First

Reference exact files (ATME_PROTOCOL.md, src/protocol/types.ts, src/protocol/mimeParser.ts) so AI extends existing interfaces cleanly instead of duplicating logic.

RULE 03

Verify With Types & Unit Tests

Require AI to add a test in src/protocol.test.ts and prove npx vitest run + npm run build succeed before committing.

RULE 04

Commit Small, Clean Diffs

Run git status and git diff before every commit. Reject leftover commented-out code, debug logs, or unused CSS selectors.

4. Authentication Checklist

Setting Up 1-Click Google Sign-In Without Errors

Google Cloud OAuth rejects misconfigured origins or pasted secrets with Error 401: invalid_client. Use this checklist when testing on your machine or deploying to Cloudflare Pages.

Step-by-Step Google Cloud Console Setup

  1. Open Google Cloud Console → APIs & Services → Credentials → Create Credentials → OAuth client ID.
  2. Choose Application Type: Web application.
  3. Under Authorized JavaScript origins, add: http://localhost:5173 (plus your live https://<your-app>.pages.dev URL).
  4. Under Authorized redirect URIs, add http://localhost:5173/ so mobile/popup-blocked fallback recovery works seamlessly too.
  5. Copy ONLY the Client ID (ends with .apps.googleusercontent.com), paste it in Account Settings → Set Google OAuth Client ID (or .env.local as VITE_GOOGLE_CLIENT_ID=...).
🔑 Open OAuth Portal & Client ID Tester

Common OAuth Mistakes Caught Automatically

❌ Error 401: invalid_client

Happens when a Client Secret (GOCSPX-...), a stray URL/quote, or a deleted Cloud Client ID is entered. @me/simple now runs validateGoogleClientId() before calling Google!

❌ Using http://127.0.0.1:5173 instead of localhost

Google blocks raw loopback IP JS origins by default. Always run and open Vite on http://localhost:5173!

✅ Testing Offline / Without Cloud Credentials

Leave the Client ID blank and click Continue with Google to use the built-in 1-Tap Demo Account Chooser immediately.
